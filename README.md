# Rotina

App no celular para marcar academia, húngaro, Fidúcia e Dota.

## Abrir no celular (GitHub Pages)

1. Abra: https://github.com/tomfauselkoch/rotina-diaria/settings/pages
2. Em **Build and deployment** → **Source**, escolha **Deploy from a branch**
3. Branch: **main** · pasta: **/ (root)** · Save
4. Espere 1–2 minutos e abra:
   https://tomfauselkoch.github.io/rotina-diaria/
5. No celular: Compartilhar → **Adicionar à Tela de Início**

Se o workflow "Deploy Pages" falhar com *environment protection rules*, ignore esse Actions e use o método acima (branch `main`).
